# RFC 0001: Obelisk knowledge and life architecture

Status: Candidate

## Problem

The current Open Frontier repository has a strong technical foundation and a compact Human Systems layer.

The broader curriculum work now includes Philosophy, Human Worlds, Expression, Mind and Design. These sources use different internal structures and cannot be safely merged by turning every record into a generic topic.

The project also needs a way to test competence in health, finance, relationships, practical independence, civic life, culture, technology and stewardship without creating a separate academic branch for every life domain.

## Proposal

Add an `Obelisk` namespace with three coordinate systems.

1. Six knowledge trunks.
2. Twelve life pillars.
3. Twelve formation modes.

Use stable IDs and typed records.

Permit different node kinds by branch.

Use source links, mastery evidence, AI modes and backtests as cross-cutting fields.

## Non-goals

- Do not replace the 22-module technical core in this RFC.
- Do not claim that candidate human branches are frozen.
- Do not treat seed cases as independent hold-outs.
- Do not make one cultural canon final.
- Do not force every field into identical granularity.

## Evidence gate

Structural validation and release readiness are separate.

The graph may merge while source stacks and hold-outs remain incomplete.

A branch becomes retained only after deletion testing, prerequisite closure, source coverage, global/temporal audit where relevant, and external hold-out evidence.

## Migration

Land the namespace additively.

Keep current Markdown and current data intact.

Generate catalogs and manifests.

Add public navigation only after structural validation passes.

Make the new graph canonical only after deterministic generation and content parity.


## V0.4 validation amendment

Replace the single-branch-holdout release gate with the claim-specific convergent validation doctrine in `docs/09-obelisk/validation-doctrine.md`. Frozen hold-outs remain mandatory where appropriate, but whole-life competence requires multiple evidence classes and eventual longitudinal observation.
