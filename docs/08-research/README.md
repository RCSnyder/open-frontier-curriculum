# Curriculum research program

Open Frontier treats its architecture as a falsifiable research program. Evidence comes from converging sources: construct/content coverage; demanding external human-acceptance criteria; process evidence; unseen transfer; adversarial stress; inter-rater evaluation; and eventually longitudinal observation.

A prestigious examination is a **proxy**, never proof of flourishing. All Souls is useful because its published acceptance criteria reward depth, analytical power, originality, original-source knowledge, breadth, responsiveness, unresolved difficulties, clarity, and further intellectual potential under severe competition.

See the [Validation Doctrine](../09-obelisk/validation-doctrine.md) and the canonical `validation-claims.json`, `proxy-registry.json`, `holdout-registry.json`, and `backtests.json`.
