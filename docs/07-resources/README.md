# Reading and civilizational inheritance

The Obelisk does not reduce civilization to summaries. It uses demanding spines, primary works, rivals, modern synthesis, cases, data/objects, global counter-cases, and professional reference.

See the canonical source registry in `data/obelisk/sources.json`.
