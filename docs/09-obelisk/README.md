# The Open Frontier Curriculum

The Obelisk is the underlying reference model for the
[Open Frontier Curriculum](../index.md), currently an unfinished public preview.
The learner experience has four foundations and integrated practice.
The six branch classifications below organize source records; they are not six competing learner-level foundations.

See [publication status and evidence](../project/evidence.md) for the current inventory and claim boundaries.

It has three coordinate systems:

1. **Knowledge trunks**: what a person must understand.
2. **Life pillars**: where that knowledge must become competent action.
3. **Formation modes**: what the learner must do for knowledge to become durable judgment, taste, skill, and agency.

The architecture does not reduce education to future-of-work skills. It preserves demanding mathematics, science, engineering, philosophy, social inquiry, literature, art, primary sources, craft, and practical life.

## Freeze rule

A branch is not retained because it resembles a university department.

Retain it only when deletion produces recurrent cross-domain damage that cannot be repaired naturally by another branch.

Freeze the architecture only after repeated heterogeneous hold-outs stop exposing new load-bearing families. Remaining failures should be explainable as missing mastery, facts, practice, or specialization.

## Evidence state

Technical Systems has attached teaching for its 22 modules. Availability is not independent evidence of instructional quality or learner mastery.

Philosophy has 117 nodes and an imported 417-prompt All Souls mapping.
The mapping does not establish unseen evaluation, independent examiner acceptance or comparative strength over other foundations.

All source classifications have recorded reading routes, but some routes lead to unselected reading areas or inherited recommendations.
Source quality, prerequisites and assessment claims still require specialist review across the collection.
No branch is promoted to reference-grade or empirically validated status by these counts.

See [Validation](validation.md).

## Foundational doctrine

The foundational documents set out the project's ambitions for lifelong human formation under changing technological conditions.
They describe design intentions, not demonstrated educational outcomes, and are read alongside the current four-foundation organization.

Start with:

- [Foundational doctrine](foundational-doctrine.md)
- [Civilizational transition model](civilizational-transition.md)
- [Human authorship and stewardship](human-authorship.md)
- [Project language and lexicon](project-lexicon.md)

The durable design question is not “what can humans still do that AI cannot?” It is: **what must humans know, practice, become and remain responsible for as machine capability increases?**
