# Graduate profile

These are outcome claims, not seat-time requirements.

| ID | Capability | Observable standard | Evidence |
| --- | --- | --- | --- |
| `GP01` | Epistemic independence | Can state what is known, inferred, assumed, uncertain, value-laden, and AI-supplied; can find and evaluate primary evidence. | Unseen claim audit + oral defense |
| `GP02` | Quantitative command | Can translate a real problem into quantities, scales, units, probabilities, models, and uncertainty. | Model + estimation + sensitivity + bound |
| `GP03` | Scientific reasoning | Can design discriminating observations/experiments and connect evidence to mechanism without overclaiming. | Experiment dossier + causal critique |
| `GP04` | Computational agency | Can reason algorithmically, automate work, understand software/network failure, and audit computational outputs. | Build + test + failure injection |
| `GP05` | Engineering judgment | Can design within constraints, trade off performance/cost/safety/maintainability, and learn from failure. | Prototype + review + teardown |
| `GP06` | Philosophical judgment | Can distinguish conceptual, empirical, logical, and normative disputes; reason about values, rights, meaning, mind, knowledge, and technology. | Unseen essay/problem + adversarial viva |
| `GP07` | Human-world diagnosis | Can model incentives, power, markets, law, organizations, culture, history, demography, conflict, and institutional change. | Comparative case + intervention design |
| `GP08` | Historical consciousness | Can place institutions, technologies, ideas, and identities in temporal sequences and recognize path dependence and contingency. | Process trace + counterfactual |
| `GP09` | Expressive command | Can read difficult texts, write clearly, speak persuasively, listen closely, revise, and adapt to audience/medium. | Portfolio + live speech + revision |
| `GP10` | Visual/spatial command | Can draw, diagram, map, visualize data, prototype interfaces/objects, and critique aesthetic-functional form. | Design studio + blind critique |
| `GP11` | Learning autonomy | Can acquire a new domain, build durable memory, practice intelligently, calibrate confidence, and teach others. | 30-day unfamiliar-domain challenge |
| `GP12` | AI stewardship | Can specify, delegate, permission, evaluate, red-team, monitor, roll back, and defend AI-assisted work. | A0–A5 dual-condition project |
| `GP13` | Practical independence | Can manage basic health, money, household systems, safety, digital security, logistics, maintenance, and emergencies. | Live demonstrations + scenarios |
| `GP14` | Relational competence | Can listen, set boundaries, negotiate, repair conflict, care for others, collaborate, and sustain trust. | Observed interaction + feedback + redo |
| `GP15` | Civic agency | Understands institutions, rights, rules, public finance, media, collective action, power, and participation. | Public decision / civic project |
| `GP16` | Economic agency | Can reason about tradeoffs, prices, work, firms, contracts, credit, insurance, investment, taxes, and long-run resource choices. | Personal/firm resource case + audit |
| `GP17` | Health agency | Can access valid health information, make risk-aware decisions, practice health-enhancing routines, and know when professional care is needed. | Health-information audit + behavior evidence |
| `GP18` | Cultural literacy & taste | Can encounter art, literature, music, architecture, religion, and traditions with historical context and discriminate quality without mistaking preference for proof. | Comparative criticism + creation |
| `GP19` | Leadership & institution building | Can create goals, roles, decision rights, feedback, dissent, accountability, and learning processes for a team or institution. | Run a real team constitution through an incident |
| `GP20` | Stewardship & future judgment | Can reason about low-probability/high-impact risks, environmental constraints, intergenerational effects, reversibility, and option value. | Long-horizon decision dossier |
| `GP21` | Craft & creation | Has at least one domain where knowledge has matured into practiced craft and can produce work others can inspect and use. | External portfolio review |
| `GP22` | Humility & update | Can find their own errors, change their mind publicly, seek expertise, and preserve unresolved uncertainty rather than manufacturing certainty. | Calibration record + documented reversals |
