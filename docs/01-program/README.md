# Program architecture

The Obelisk has three coordinate systems.

- **Knowledge trunks** provide durable models and civilizational inheritance.
- **Life pillars** force knowledge to answer to lived competence.
- **Formation modes** specify the experiences through which knowledge becomes capability.

The system is governed by stable IDs, typed prerequisites/interfaces, deletion tests, source provenance, mastery gates, AI-use modes, and validation claims.
