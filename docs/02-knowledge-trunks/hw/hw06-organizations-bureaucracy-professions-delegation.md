# HW06  -  Organizations, Bureaucracy, Professions & Delegation

**Branch:** Human Worlds
**Status:** candidate-v2
**Prerequisites:** HW02, HW03, HW04, HW05

## Exit capability

Trace decision and information chains inside organizations and redesign oversight without destroying useful discretion.

## Core concepts

division of labor, hierarchy, delegation, principal-agent, discretion, expertise, professions, routines, metrics

## Deletion test

Organizations are not unitary actors; deleting this hides agency loss, expertise, routines, and metric gaming.

## Mastery gate

Delegation map + metric audit + redesign
