# HW05  -  Collective Action, Public Goods, Commons & Public Choice

**Branch:** Human Worlds
**Status:** candidate-v2
**Prerequisites:** HW03, HW04

## Exit capability

Diagnose coordination failures and compare governance arrangements with explicit assumptions and gaming risks.

## Core concepts

public goods, common-pool resources, free riding, clubs, selective incentives, monitoring, sanctions, collective choice

## Deletion test

Shared interest does not imply coordinated action; this mechanism recurs from teams to climate governance.

## Mastery gate

Commons/public-good design + failure mode + defense
