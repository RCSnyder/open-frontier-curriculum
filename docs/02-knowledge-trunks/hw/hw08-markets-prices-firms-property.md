# HW08  -  Markets, Prices, Firms & Property

**Branch:** Human Worlds
**Status:** candidate-v2
**Prerequisites:** HW01, HW03, HW05

## Exit capability

## Core concepts

supply/demand, price signals, elasticity, competition, market power, externalities, transaction costs, firms, contracts, property

## Deletion test
