# HW07  -  Power, Authority, Legitimacy & Resistance

**Branch:** Human Worlds
**Status:** candidate-v2
**Prerequisites:** HW01, HW02, HW03, HW04, HW05, HW06

## Exit capability

## Core concepts

coercion, dependence, agenda control, preference shaping, authority, legitimacy, domination, exit, voice, resistance
