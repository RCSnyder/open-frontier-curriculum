# HW11  -  Regimes, Representation, Parties, Media & Political Competition

**Branch:** Human Worlds
**Status:** candidate-v2
**Prerequisites:** HW04, HW07, HW10

## Exit capability

## Core concepts

democracy/autocracy, representation, voting, parties, coalitions, interest groups, media, public opinion, agenda setting
