# HW01  -  Social Evidence, Interpretation & Comparative Method

**Branch:** Human Worlds
**Status:** candidate-v2
**Prerequisites:** None

## Exit capability

Separate observation, inference, model, interpretation, and normative claim; build competing causal stories and identify discriminating evidence.

## Core concepts

claim ledger, source criticism, construct validity, case comparison, process tracing, qualitative/quantitative triangulation

## Deletion test

Without this, every later social claim can become anecdote, ideological assertion, or false precision.

## Mastery gate

Unseen mixed-source case + rival explanation + defense
