# Philosophy & Judgment

Methods, logic, knowledge, reality, mind, action, language, value, politics, law, science, technology, world traditions and transformative frameworks.

## Why this trunk survives deletion

The learner can execute but cannot reliably distinguish conceptual, empirical, logical and normative disputes or justify beliefs and values.
