# EX-M01  -  Grammar & Sentence Architecture

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** None

## Exit capability

Build, parse, combine, split, and deliberately vary English sentences while preserving exact logical relations.

## Core concepts

clause, phrase, subject/predicate, coordination/subordination, modification, agreement, tense/aspect, punctuation, parallelism, marked word order

## Deletion test

If missing, every higher expressive task becomes unreliable: ambiguity, rhythm, emphasis, and argument can fail at sentence level.

## Mastery gate

Parse + reconstruct + sentence transformation + defense

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-001 | Parse unfamiliar sentences into clauses and explain the function of major phrases and modifiers. | Reconstruct |
| EX-LO-002 | Generate at least five syntactically different sentences expressing the same logical proposition. | Transfer |
| EX-LO-003 | Use punctuation, coordination, subordination, and word order to control emphasis and relation rather than merely obey rules. | Break / Bound |
| EX-LO-004 | Diagnose ambiguity or unintended implication caused by grammatical structure and repair it without loss of nuance. | Check / Defend |
