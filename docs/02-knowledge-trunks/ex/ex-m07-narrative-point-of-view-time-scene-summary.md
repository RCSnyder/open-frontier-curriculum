# EX-M07  -  Narrative: Point of View, Time, Scene & Summary

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02, EX-M03, EX-M04, EX-M05, EX-M06

## Exit capability

Narrate the same events under different viewpoints, time structures, and information constraints while controlling reader inference.

## Core concepts

event, story/discourse, narrator, focalization, first/third person, free indirect discourse, scene, summary, duration, order, omission, revelation

## Deletion test

If missing, experience cannot be shaped into intelligible stories or causal sequences.

## Mastery gate

Retell event under changed POV/time + narrative diagnosis

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-025 | Separate event sequence from discourse order and explain how rearrangement changes suspense, causality, or sympathy. | Reconstruct |
| EX-LO-026 | Retell one event in first person, limited third, omniscient, and free indirect styles with controlled information access. | Transfer |
| EX-LO-027 | Move deliberately among scene, summary, pause, ellipsis, and description. | Break / Bound |
| EX-LO-028 | Design revelation and omission so the reader can infer more than is explicitly stated. | Check / Defend |
