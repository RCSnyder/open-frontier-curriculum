# EX-M03  -  Cohesion, Paragraphs & Information Flow

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02

## Exit capability

Control what the reader knows, expects, and notices from sentence to sentence and paragraph to paragraph.

## Core concepts

topic/focus, old-to-new information, given/new, reference, transition, paragraph unity, progression, emphasis, periodic/cumulative movement

## Deletion test

If missing, locally good sentences fail to become intelligible sustained thought.

## Mastery gate

Reorder/revise passage + unseen exposition problem

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-009 | Arrange sentences so given information leads readers toward new information with minimal processing confusion. | Reconstruct |
| EX-LO-010 | Build paragraphs with a discernible controlling movement rather than a pile of related statements. | Transfer |
| EX-LO-011 | Control pronoun/reference chains, transitions, parallel structure, and emphasis across multiple paragraphs. | Break / Bound |
| EX-LO-012 | Rewrite a confusing passage by changing order and information structure without simplifying the underlying idea. | Check / Defend |
