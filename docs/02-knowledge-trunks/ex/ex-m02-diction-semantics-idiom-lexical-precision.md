# EX-M02  -  Diction, Semantics, Idiom & Lexical Precision

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01

## Exit capability

Choose words for exact meaning, implication, register, rhythm, and social effect; diagnose near-synonym differences.

## Core concepts

denotation, connotation, polysemy, register, collocation, idiom, metaphorical extension, synonym contrast, etymology as clue not proof

## Deletion test

If missing, the writer can form grammatical sentences but cannot reliably say exactly the thing intended.

## Mastery gate

Definition contrasts + lexical substitution + boundary cases

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-005 | Define a word operationally enough to separate it from close alternatives, with positive examples and boundary cases. | Reconstruct |
| EX-LO-006 | Choose among near-synonyms by denotation, connotation, register, collocation, rhythm, and audience. | Transfer |
| EX-LO-007 | Recognize idiomatic versus merely grammatical phrasing and revise unnatural collocations. | Break / Bound |
| EX-LO-008 | Use dictionaries/corpora as evidence while resisting etymological fallacies and false precision. | Check / Defend |
