# EX-M05  -  Image, Figurative Language & Analogy

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02, EX-M03, EX-M04

## Exit capability

Render perception, emotion, abstraction, and relation through concrete language and controlled figurative structures.

## Core concepts

image, concrete detail, metaphor, simile, metonymy, synecdoche, personification, symbol, analogy, conceit, literal/figurative interaction

## Deletion test

If missing, English remains propositionally usable but loses compression, vividness, discovery, and many forms of emotional precision.

## Mastery gate

Concrete rendering + figure generation + failed-analogy diagnosis

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-017 | Translate an abstraction into concrete images and then recover the abstraction without distortion. | Reconstruct |
| EX-LO-018 | Generate multiple metaphors/analogies for one relation and identify where each mapping fails. | Transfer |
| EX-LO-019 | Distinguish symbol, metaphor, simile, metonymy, synecdoche, and literal description in actual passages. | Break / Bound |
| EX-LO-020 | Use figurative language to discover or compress thought rather than merely ornament prose. | Check / Defend |
