# EX-M04  -  Rhetoric, Argument, Audience & Occasion

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02, EX-M03

## Exit capability

Make a precise case for a skeptical audience, adapt it to occasion, and distinguish persuasion from proof.

## Core concepts

claim, reason, evidence, warrant, counterargument, concession, audience, purpose, exigence, ethos/pathos/logos, framing, arrangement

## Deletion test

If missing, expression cannot reliably change minds, defend propositions, or survive disagreement.

## Mastery gate

Argument map + counterargument + audience transformation + oral defense

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-013 | Map an argument into claim, reasons, evidence, warrants, assumptions, and counterarguments. | Reconstruct |
| EX-LO-014 | Adapt the same proposition to hostile, neutral, expert, and general audiences without changing what counts as evidence. | Transfer |
| EX-LO-015 | Distinguish rhetorical effectiveness from logical or empirical support. | Break / Bound |
| EX-LO-016 | Concede, qualify, rebut, or revise in response to a serious counterargument rather than caricaturing opposition. | Check / Defend |
