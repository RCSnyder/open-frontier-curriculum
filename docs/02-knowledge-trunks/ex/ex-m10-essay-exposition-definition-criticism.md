# EX-M10  -  Essay, Exposition, Definition & Criticism

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02, EX-M03, EX-M04, EX-M05, EX-M06, EX-M07, EX-M08, EX-M09

## Exit capability

Explain difficult ideas clearly, define contested terms, compare models, and write interpretive criticism supported by textual evidence.

## Core concepts

question, thesis, definition, distinction, example, classification, causal explanation, comparison, close analysis, synthesis, qualification

## Deletion test

If missing, the learner can create effects but cannot reliably expose reasoning and interpretation to inspection.

## Mastery gate

Analytical essay + definition test + evidence defense

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-037 | Frame a genuine question and produce a thesis that is arguable, scoped, and answerable by available evidence. | Reconstruct |
| EX-LO-038 | Define, classify, compare, and explain complex material without hiding uncertainty. | Transfer |
| EX-LO-039 | Perform close textual analysis that connects quoted or described detail to an interpretive claim. | Break / Bound |
| EX-LO-040 | Write criticism that represents rival readings fairly and states what evidence would force revision. | Check / Defend |
