# EX-M13  -  Oral English, Cadence, Speech & Performance

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02, EX-M03, EX-M04, EX-M05, EX-M06, EX-M07, EX-M08, EX-M09, EX-M10, EX-M11, EX-M12

## Exit capability

Turn written English into intelligible, persuasive, memorable speech and compose with the ear as well as the eye.

## Core concepts

breath group, stress, pause, cadence, emphasis, pace, pitch contour, rhetorical period, spoken register, memorization, delivery, audience feedback

## Deletion test

If missing, expressive control is confined to silent prose and misses spoken timing, emphasis, and embodied rhetoric.

## Mastery gate

Read-aloud revision + extemporaneous speech + oral defense

## Formation modes

R, S, P, M, D, B, C, V, L

## AI modes

A0, A1, A2, A4, A5

## Nodes / outcomes

| ID | Capability | Mastery |
| --- | --- | --- |
| EX-LO-049 | Mark prose for breath, stress, pause, pace, and emphasis, then revise syntax to improve live intelligibility. | Reconstruct |
| EX-LO-050 | Deliver a short argument extemporaneously from an outline rather than reading sentences. | Transfer |
| EX-LO-051 | Use rhetorical repetition, parallelism, cadence, and timing without sounding accidental or inflated. | Break / Bound |
| EX-LO-052 | Diagnose the difference between a text that reads well silently and one that works when heard once. | Check / Defend |
