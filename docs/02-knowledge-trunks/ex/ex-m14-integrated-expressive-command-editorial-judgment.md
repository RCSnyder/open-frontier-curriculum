# EX-M14  -  Integrated Expressive Command & Editorial Judgment

**Branch:** Expression & Interpretation
**Status:** candidate-strong
**Prerequisites:** EX-M01, EX-M02, EX-M03, EX-M04, EX-M05, EX-M06, EX-M07, EX-M08, EX-M09, EX-M10, EX-M11, EX-M12, EX-M13

## Exit capability

Express the same difficult content as explanation, argument, narrative, dialogue, lyric, speech, and concise summary; edit each toward exact intended effect.

## Core concepts

intention, audience, medium, form, structure, syntax, diction, image, voice, evidence, rhythm, revision, deletion, amplification, ethical representation

## Deletion test

This is the target itself: integration proves the components are available on demand rather than stored as separate coursework.

## Mastery gate

Capstone portfolio + unseen transformation exam + final defense
