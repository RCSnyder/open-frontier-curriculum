# DR04  -  Data Visualization & Information Design

**Branch:** Design & Representation
**Status:** candidate-compression-test
**Prerequisites:** DR01, DR02, DR03

## Exit capability

Choose visual encodings that reveal rather than distort quantity, uncertainty, and comparison.

## Core concepts

encoding, scale, comparison, uncertainty, annotation, small multiples, perceptual honesty

## Deletion test

AI can make beautiful charts that are epistemically bad.

## Mastery gate

Misleading-vs-honest redesign + unseen dataset
