# DR11  -  Prototyping, User Research, Critique & Iteration

**Branch:** Design & Representation
**Status:** candidate-compression-test
**Prerequisites:** DR01, DR02, DR03, DR04, DR05, DR06, DR07, DR08, DR09, DR10

## Exit capability

Turn uncertain assumptions into prototypes and observations; revise without overfitting to one user.

## Core concepts

prototype, observation, interview, usability, critique, iteration, tradeoff, evidence

## Deletion test

Design claims need evidence, not designer confidence.

## Mastery gate

Prototype-test-revise loop + negative findings
