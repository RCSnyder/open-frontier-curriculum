# Formation system

## Teaching studios

- [Learning evidence lab](learning-evidence-lab.md): baseline, retention, transfer and rival explanations.
- [Comparative institutions lab](comparative-institutions-lab.md): commons, incentives and legitimate action.
- [Whole-work studio](whole-work-studio.md): complete encounter, close reading and interpretive defense.
- [Design judgment studio](design-judgment-studio.md): compare, make, observe and revise.
- [Examiner calibration](examiner-calibration.md): independent scoring, disagreement and appeals.

These are concrete teaching routes, not evidence of measured learner outcomes.

| Code | Mode | Purpose | Evidence |
| --- | --- | --- | --- |
| R | Read / Encounter | Acquire contact with the thing itself before excessive summary. | Annotated reading/field ledger |
| S | Study / Reconstruct | Create durable internal models. | Closed-book reconstruction |
| P | Practice / Drill | Convert declarative knowledge into fluent capability. | Practice log + performance curve |
| M | Make / Investigate | Learn constraints through production. | Inspectible artifact + process record |
| D | Dialogue / Critique | Expose hidden assumptions and learn in intellectual community. | Discussion/critique record |
| A | Apply / Serve | Discover consequences absent from classroom exercises. | Stakeholder/field evidence |
| B | Break / Red-team | Train robustness rather than polished normal cases. | Failure catalogue |
| C | Compare / Curate | Form discriminating judgment under abundance. | Blind ranking + curation statement |
| F | Forecast / Decide | Turn uncertainty into calibrated judgment. | Scored forecast / decision journal |
| T | Teach / Translate | Reveal whether knowledge is organized enough to explain. | Learner pre/post or audience evidence |
| V | Viva / Defend | Verify ownership of the work. | Examiner record |
| L | Longitudinal Retest | Distinguish task performance from retained learning. | Delayed score / transfer artifact |

## AI use

| Mode | Name | Rule | Pass condition |
| --- | --- | --- | --- |
| A0 | Human-only acquisition | No general-purpose AI during first reconstruction. | Fail if learner cannot explain from memory at required granularity. |
| A1 | AI as tutor / questioner | AI may ask questions, generate practice, give bounded hints, or simulate an examiner. | Pass only if gains persist without AI. |
| A2 | AI as copilot | AI may draft alternatives, code, search, simulate, translate, or critique. | Polish alone receives no credit. |
| A3 | AI as delegated agent | AI may execute multi-step work with tools under permissions. | Learner must predict likely failure classes before run. |
| A4 | AI as adversary / red team | AI deliberately attacks claims, designs, incentives, security, and reasoning. | Pass requires changing something important when attack succeeds. |
| A5 | Human defense / fallback | AI removed; learner defends decisions, key models, evidence, and uncertainty. | Pass only if learner can distinguish what they know from what the AI supplied. |
