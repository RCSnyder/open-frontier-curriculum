# Foundations I

Use the cards to forage; use the module numbers when following the recommended sequence.

<div class="grid cards ofc-module-grid" markdown>

-   <span class="ofc-card-title">**[01 / Mathematical reasoning + proof](01-mathematical-reasoning-proof.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> None beyond algebra</span>

    <span class="ofc-card-copy"><b>Exit:</b> Own definitions, quantifiers, implication, counterexample, induction, proof structure.</span>

-   <span class="ofc-card-title">**[02 / Calculus + vector calculus](02-calculus-vector-calculus.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Algebra/trigonometry + Module 1</span>

    <span class="ofc-card-copy"><b>Exit:</b> Own limits, derivatives as local linearization, integrals as accumulation, gradients/Jacobians, line/surface integrals and field theorems.</span>

-   <span class="ofc-card-title">**[03 / Linear algebra](03-linear-algebra.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 1-2 can overlap</span>

    <span class="ofc-card-copy"><b>Exit:</b> Own vector spaces, projections, least squares, matrix maps, rank/nullspace, conditioning, SVD/eigenstructure.</span>

-   <span class="ofc-card-title">**[04 / ODEs + dynamical systems](04-odes-dynamical-systems.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 2-3</span>

    <span class="ofc-card-copy"><b>Exit:</b> Translate changing systems into state equations; solve/analyze equilibria, stability, oscillation, nonlinear behavior and feedback.</span>

-   <span class="ofc-card-title">**[05 / Probability](05-probability.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 1-3</span>

    <span class="ofc-card-copy"><b>Exit:</b> Quantify uncertainty, conditioning, expectation, dependence, transformations, concentration and asymptotics.</span>

-   <span class="ofc-card-title">**[06 / Statistics + causal inference](06-statistics-causal-inference.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Module 5; basic linear algebra</span>

    <span class="ofc-card-copy"><b>Exit:</b> Define estimands; separate prediction from intervention; identify confounding/selection/measurement bias; estimate and stress-test effects.</span>

-   <span class="ofc-card-title">**[07 / Scientific computing](07-scientific-computing.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 2-5</span>

    <span class="ofc-card-copy"><b>Exit:</b> Know conditioning, numerical stability, approximation, iterative solution, ODE/PDE discretization and computational verification.</span>

-   <span class="ofc-card-title">**[08 / Optimization](08-optimization.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 2-3, 5, 7</span>

    <span class="ofc-card-copy"><b>Exit:</b> Formulate objectives/constraints; understand convexity, duality, KKT conditions and numerical optimization; audit objectives.</span>

-   <span class="ofc-card-title">**[09 / Information + signals](09-information-signals.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 3, 5, 7</span>

    <span class="ofc-card-copy"><b>Exit:</b> Own entropy, mutual information, channel capacity, transforms, sampling, filtering, spectral reasoning and estimation limits.</span>

-   <span class="ofc-card-title">**[10 / Control + estimation](10-control-estimation.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 3-5, 7-9</span>

    <span class="ofc-card-copy"><b>Exit:</b> Design closed loops; analyze stability/robustness; infer hidden state; reason about controllability, observability and tradeoffs.</span>

-   <span class="ofc-card-title">**[11 / Metrology + experiments](11-metrology-experiments.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Module 5; runs in parallel from Week 1</span>

    <span class="ofc-card-copy"><b>Exit:</b> Calibrate, quantify uncertainty, design informative experiments, distinguish process variation from measurement variation, reproduce results.</span>
