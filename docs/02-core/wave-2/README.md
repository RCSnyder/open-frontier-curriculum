# Foundations II

    <span class="ofc-card-copy"><b>Exit:</b> Convert forces, fields and conservation laws into predictive models; move between particle, rigid-body, orbital and field descriptions.</span>

-   <span class="ofc-card-title">**[02 / Thermodynamics + statistical mechanics](02-thermodynamics-statistical-mechanics.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Wave 1 probability, calculus, ODEs</span>

    <span class="ofc-card-copy"><b>Exit:</b> Track energy/entropy/free energy; derive equilibrium tendencies; connect microscopic states to macroscopic limits and transport.</span>

-   <span class="ofc-card-title">**[03 / Quantum + condensed matter](03-quantum-condensed-matter.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Wave 1 linear algebra, ODEs, probability; Module 1</span>

    <span class="ofc-card-copy"><b>Exit:</b> Reason with wavefunctions/operators and connect quantum states to bands, semiconductors, phonons, magnetism and superconductivity.</span>

-   <span class="ofc-card-title">**[04 / Chemistry + materials](04-chemistry-materials.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 1-3; Wave 1 thermo/optimization concepts</span>

    <span class="ofc-card-copy"><b>Exit:</b> Predict bonding, reaction direction/rate, electrochemistry, diffusion, phase behavior and processing-structure-property links.</span>

-   <span class="ofc-card-title">**[05 / Electronics + embedded systems](05-electronics-embedded-systems.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Module 1; Wave 1 signals/control</span>

    <span class="ofc-card-copy"><b>Exit:</b> Design and instrument circuits from passive networks through semiconductor interfaces, sensing, power conversion and real-time embedded control.</span>

-   <span class="ofc-card-title">**[06 / Mechanical design + fluids + structures](06-mechanical-design-fluids-structures.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Module 1; Module 4; Wave 1 control/optimization</span>

    <span class="ofc-card-copy"><b>Exit:</b> Turn loads and flows into safe geometry; reason about stress, fatigue, shells, fluids, pumps, pressure systems and mass-efficient structures.</span>

-   <span class="ofc-card-title">**[07 / Molecular + cell biology](07-molecular-cell-biology.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Module 2; Module 4; Wave 1 dynamics/probability</span>

    <span class="ofc-card-copy"><b>Exit:</b> Model cells as chemical, energetic, informational and mechanical systems; understand membranes, metabolism, signaling, division and gene expression.</span>

-   <span class="ofc-card-title">**[08 / Genetics + evolution + systems biology](08-genetics-evolution-systems-biology.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Module 7; Wave 1 dynamics/probability/causal inference</span>

    <span class="ofc-card-copy"><b>Exit:</b> Reason about inheritance, variation, population change, gene circuits, network motifs, stochastic expression and evolutionary robustness.</span>

-   <span class="ofc-card-title">**[09 / Neuroscience + physiology](09-neuroscience-physiology.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 5,7; Wave 1 signals/control/probability</span>

    <span class="ofc-card-copy"><b>Exit:</b> Connect electrophysiology and neural coding to whole-body homeostasis, cardiovascular/respiratory/endocrine/renal control.</span>

-   <span class="ofc-card-title">**[10 / Manufacturing + operations](10-manufacturing-operations.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> Modules 4-6; Wave 1 optimization/metrology</span>

    <span class="ofc-card-copy"><b>Exit:</b> Translate prototypes into processes with rate, yield, variation, quality, cost, maintenance, supply chain and learning curves.</span>

-   <span class="ofc-card-title">**[11 / Safety + reliability + security](11-safety-reliability-security.md)**</span>

    <span class="ofc-card-copy"><b>Prerequisite:</b> All prior modules; Wave 1 causal/metrology/control</span>

    <span class="ofc-card-copy"><b>Exit:</b> Design systems that remain safe and dependable under component failure, software defects, organizational drift, misuse and adversaries.</span>
