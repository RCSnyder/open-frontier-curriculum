# Human systems & deployment

Technical capability does not determine objectives, legitimacy, incentives, risk distribution, or institutional behavior. These pages attach humanistic and social-scientific questions to concrete technical artifacts.

| Week | Question | Artifact changed |
|---:|---|---|
| 125 | How reliable is the story / source? | claim ledger / historical context |
| 126 | Who benefits, who bears error, who has recourse? | objective / evaluation |
| 127 | Who has power and veto rights? | governance / decision rights |
| 128 | What do metrics and incentives reward? | anti-Goodhart tests |
| 129 | How does failure become normalized? | monitoring / stop-work authority |
| 130 | Is the problem itself contested? | reversible portfolio / reformulation |
| 131 | Is disagreement factual, normative, or relational? | decision record / conflict process |
| 132 | What is economically binding? | cost / real-options model |
| 133 | What rules actually apply? | compliance / standards matrix |
| 134 | Can another person reproduce the claim? | release package |
| 135 | What institution keeps learning when leaders are wrong? | lab / team constitution |
| 136 | What should happen next? | public defense / 12-month program |
