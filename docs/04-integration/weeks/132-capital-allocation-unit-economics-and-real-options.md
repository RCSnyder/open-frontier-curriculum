# Week 132: Capital allocation, unit economics and real options

**Theme:** Economics

**Reading/source:** Wave-1/2 economics + project finance/decision analysis; use current costs from public sources relevant to your track

**Learning outcome:** Translate technical performance into cost, capital intensity, learning curve, option value and staged investment.

**Required analysis:** Build bottom-up cost model and identify the technical parameter with greatest economic elasticity.

**Artifact that must change:** Design a staged financing/research plan where each tranche buys information and preserves abandonment option.

**Oral defense:** Which technical breakthrough would *not* make the project economically deployable?

**Pass criterion:** Pass if a technical improvement is rejected because another bottleneck dominates total value.

**Function:** Economics / capital

**Access/source:** Use current public cost sources; document date and scenario.
