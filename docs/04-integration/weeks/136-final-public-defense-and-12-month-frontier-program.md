# Week 136: Final public defense and 12-month frontier program

**Theme:** Launch

**Reading/source:** All prior work; no new reading

**Learning outcome:** Integrate technical, empirical, economic, institutional and human evidence into a bounded thesis and action program.

**Required analysis:** From blank page: state problem, physical/causal model, evidence, uncertainty, bottleneck, stakeholders/power, risks, economics and next experiment.

**Pass criterion:** Final pass requires technically credible work, explicit uncertainty, reproducibility, moral/political self-critique and a falsifiable next move.

**Function:** Integration / launch
