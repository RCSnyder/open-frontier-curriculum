# Week 131: Nonviolent communication, difficult conversations and design conflict

**Theme:** Conflict

**Reading/source:** CNVC NVC framework + Difficult Conversations + Conscious Leadership resources

**Learning outcome:** Separate observation from interpretation, surface interests/needs, handle identity threat, and preserve adversarial technical disagreement.

**Required analysis:** Run a recorded design review with two assigned roles whose incentives conflict; first use adversarial bargaining, then structured listening/request methods.

**Artifact that must change:** Write decision record: disagreements, evidence, unresolved interests, concessions and test that can decide technical dispute.

**Oral defense:** What conflict is about facts, what is about values, and what is about status/identity/power?

**Pass criterion:** Pass if the team reaches clearer disagreement or a better experiment-not necessarily consensus.

**Function:** Communication / leadership

**Access/source:** https://www.cnvc.org/learn/what-is-nvc | https://conscious.is/resources/
