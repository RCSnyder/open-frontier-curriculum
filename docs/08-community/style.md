# Writing style

Use plain technical English. Favor exact terms, direct sentences, and compact reference formats.

## Rules

- Put the main claim first.
- Name the actor when the actor matters.
- Prefer active voice.
- Keep one term for one concept.
- Define technical terms; do not replace them with easier but less precise synonyms.
- Prefer verbs to noun phrases.
- Use sentence-case headings.
- Cite named sources for current factual claims.
- Separate fact, inference, and opinion.
- Remove sentences that only add tone, suspense, or motivation.
- Use fragments in reference schemas when the field label supplies the context.

## AI-writing patterns

Avoid repeated rhetorical pivots, dramatic em dashes, fake suspense, generic preambles, invented labels, marketing language, vague attribution, synonym cycling, and repeated conclusions.

The full repository guide is `STYLE.md`. It draws from plain-language guidance, ASD-STE100, newsroom editing, Hemingway-style compression, and [tropes.fyi](https://tropes.fyi/). The repository does not claim ASD-STE100 compliance and does not reproduce the AP Stylebook.
