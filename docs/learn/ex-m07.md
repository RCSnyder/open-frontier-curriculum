# Narrative: Point of View, Time, Scene & Summary

[Expressive Command](../foundations/representation.md)

## What you will develop

Narrate the same events under different viewpoints, time structures, and information constraints while controlling reader inference.

## Study and practice

This is a study outline. A complete practice sequence is not yet available.

- event
- story/discourse
- narrator
- focalization
- first/third person
- free indirect discourse
- scene
- summary
- duration
- order
- omission
- revelation

### Separate event sequence from discourse order and explain how rearrangement changes suspense, causality, or sympathy. {#ex-lo-025}

Reconstruct

### Retell one event in first person, limited third, omniscient, and free indirect styles with controlled information access. {#ex-lo-026}

Transfer

### Move deliberately among scene, summary, pause, ellipsis, and description. {#ex-lo-027}

Break / Bound

### Design revelation and omission so the reader can infer more than is explicitly stated. {#ex-lo-028}

Check / Defend

### Intended demonstration

Retell event under changed POV/time + narrative diagnosis

This describes the intended standard, not a validated assessment or a claim of mastery.
