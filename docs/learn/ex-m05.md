# Image, Figurative Language & Analogy

[Expressive Command](../foundations/representation.md)

## What you will develop

Render perception, emotion, abstraction, and relation through concrete language and controlled figurative structures.

## Study and practice

This is a study outline. A complete practice sequence is not yet available.

- image
- concrete detail
- metaphor
- simile
- metonymy
- synecdoche
- personification
- symbol
- analogy
- conceit
- literal/figurative interaction

### Translate an abstraction into concrete images and then recover the abstraction without distortion. {#ex-lo-017}

Reconstruct

### Generate multiple metaphors/analogies for one relation and identify where each mapping fails. {#ex-lo-018}

Transfer

### Distinguish symbol, metaphor, simile, metonymy, synecdoche, and literal description in actual passages. {#ex-lo-019}

Break / Bound

### Use figurative language to discover or compress thought rather than merely ornament prose. {#ex-lo-020}

Check / Defend

### Intended demonstration

Concrete rendering + figure generation + failed-analogy diagnosis

This describes the intended standard, not a validated assessment or a claim of mastery.
