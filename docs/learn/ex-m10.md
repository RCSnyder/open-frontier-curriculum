# Essay, Exposition, Definition & Criticism

[Expressive Command](../foundations/representation.md)

## What you will develop

Explain difficult ideas clearly, define contested terms, compare models, and write interpretive criticism supported by textual evidence.

## Study and practice

This is a study outline. A complete practice sequence is not yet available.

- question
- thesis
- definition
- distinction
- example
- classification
- causal explanation
- comparison
- close analysis
- synthesis
- qualification

### Frame a genuine question and produce a thesis that is arguable, scoped, and answerable by available evidence. {#ex-lo-037}

Reconstruct

### Define, classify, compare, and explain complex material without hiding uncertainty. {#ex-lo-038}

Transfer

### Perform close textual analysis that connects quoted or described detail to an interpretive claim. {#ex-lo-039}

Break / Bound

### Write criticism that represents rival readings fairly and states what evidence would force revision. {#ex-lo-040}

Check / Defend

### Intended demonstration

Analytical essay + definition test + evidence defense

This describes the intended standard, not a validated assessment or a claim of mastery.
