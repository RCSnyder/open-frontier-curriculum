# Perception, Motor Learning & Embodied Skill

[Learning to learn](../foundations/learning.md)

## What you will develop

Acquire and refine a physical skill through observation, practice, feedback, and adaptation.

## Study and practice

This is a study outline. A complete practice sequence is not yet available.

- perception-action loop
- sensorimotor calibration
- variability
- feedback
- automaticity
- manual skill

### Perception-action loops {#ml10-n01}

Reconstruct  ->  apply  ->  perturb  ->  measure  ->  defend.

### Sensorimotor calibration {#ml10-n02}

Reconstruct  ->  apply  ->  perturb  ->  measure  ->  defend.

### Variable practice & motor adaptation {#ml10-n03}

Reconstruct  ->  apply  ->  perturb  ->  measure  ->  defend.

### Embodied / manual skill transfer {#ml10-n04}

Reconstruct  ->  apply  ->  perturb  ->  measure  ->  defend.

### Intended demonstration

New physical skill + video/measurement evidence + transfer

This describes the intended standard, not a validated assessment or a claim of mastery.
