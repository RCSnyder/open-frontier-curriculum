# Prototyping, User Research, Critique & Iteration

[Expressive Command](../foundations/representation.md)

## What you will develop

Turn uncertain assumptions into prototypes and observations; revise without overfitting to one user.

## Study and practice

This is a study outline. A complete practice sequence is not yet available.

- prototype
- observation
- interview
- usability
- critique
- iteration
- tradeoff
- evidence

### Prototype fidelity & hypothesis choice {#dr11-n01}

Reconstruct  ->  compare  ->  make  ->  critique  ->  revise  ->  defend.

### Observation / interview / usability evidence {#dr11-n02}

Reconstruct  ->  compare  ->  make  ->  critique  ->  revise  ->  defend.

### Critique language & structured review {#dr11-n03}

Reconstruct  ->  compare  ->  make  ->  critique  ->  revise  ->  defend.

### Iteration, tradeoffs & negative findings {#dr11-n04}

Reconstruct  ->  compare  ->  make  ->  critique  ->  revise  ->  defend.

### Intended demonstration

Prototype-test-revise loop + negative findings

This describes the intended standard, not a validated assessment or a claim of mastery.
