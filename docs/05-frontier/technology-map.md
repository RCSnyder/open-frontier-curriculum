# Dependency pattern

Every frontier page uses the same routing pattern:

```mermaid
flowchart LR
    T[Technology] --> B[Current bottleneck]
    B --> S[Specialization]
    S --> P[Physical / biological / industrial substrates]
    P --> F[Mathematical / inferential foundations]
    F --> W[Proof of work]
    W --> B
```
