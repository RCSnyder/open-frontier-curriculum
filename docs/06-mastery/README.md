# Mastery and acceptance

The Obelisk records multiple mastery dimensions rather than one grade.

| Code | Dimension | What it records | Observable standard |
| --- | --- | --- | --- |
| K | Knowledge | Retained facts, definitions, exemplars, vocabulary, chronology, canonical results. | Can recall and recognize without aid where foundational. |
| M | Models | Internal explanatory/formal structures and assumptions. | Can reconstruct and explain mechanisms. |
| T | Transfer | Ability to apply in unfamiliar domains/representations. | Solves unseen variations without template matching. |
| P | Practice | Procedural/embodied fluency and execution quality. | Can perform reliably under realistic constraints. |
| J | Judgment | Selection among tradeoffs under uncertainty and conflicting values. | Can defend criteria, update, and preserve uncertainty. |
| C | Communication | Writing, speech, visual representation, listening, teaching. | Adapts to audience and medium without corrupting content. |
| A | AI Stewardship | Tool choice, delegation, evals, provenance, monitoring, fallback. | Can improve outcomes with AI while retaining ownership and safety. |
| R | Reality contact | Evidence from measurement, users, field, operations, primary sources, or physical artifacts. | Can identify where model meets territory and where it fails. |
| E | Ethics / responsibility | Stakeholder, rights, safety, legitimacy, professional duty, recourse. | Can identify responsibility and act proportionately. |
| L | Learning autonomy | Can diagnose gaps, design practice, seek feedback, retain and renew competence. | Can teach self into a new domain. |
| S | Stewardship | Long-horizon, institutional, environmental, intergenerational responsibility. | Preserves option value and learning capacity. |

## Graduate profile

| ID | Capability | Observable standard |
| --- | --- | --- |
| GP01 | Epistemic independence | Can state what is known, inferred, assumed, uncertain, value-laden, and AI-supplied; can find and evaluate primary evidence. |
| GP02 | Quantitative command | Can translate a real problem into quantities, scales, units, probabilities, models, and uncertainty. |
| GP03 | Scientific reasoning | Can design discriminating observations/experiments and connect evidence to mechanism without overclaiming. |
| GP04 | Computational agency | Can reason algorithmically, automate work, understand software/network failure, and audit computational outputs. |
| GP05 | Engineering judgment | Can design within constraints, trade off performance/cost/safety/maintainability, and learn from failure. |
| GP06 | Philosophical judgment | Can distinguish conceptual, empirical, logical, and normative disputes; reason about values, rights, meaning, mind, knowledge, and technology. |
| GP07 | Human-world diagnosis | Can model incentives, power, markets, law, organizations, culture, history, demography, conflict, and institutional change. |
| GP08 | Historical consciousness | Can place institutions, technologies, ideas, and identities in temporal sequences and recognize path dependence and contingency. |
| GP09 | Expressive command | Can read difficult texts, write clearly, speak persuasively, listen closely, revise, and adapt to audience/medium. |
| GP10 | Visual/spatial command | Can draw, diagram, map, visualize data, prototype interfaces/objects, and critique aesthetic-functional form. |
| GP11 | Learning autonomy | Can acquire a new domain, build durable memory, practice intelligently, calibrate confidence, and teach others. |
| GP12 | AI stewardship | Can specify, delegate, permission, evaluate, red-team, monitor, roll back, and defend AI-assisted work. |
| GP13 | Practical independence | Can manage basic health, money, household systems, safety, digital security, logistics, maintenance, and emergencies. |
| GP14 | Relational competence | Can listen, set boundaries, negotiate, repair conflict, care for others, collaborate, and sustain trust. |
| GP15 | Civic agency | Understands institutions, rights, rules, public finance, media, collective action, power, and participation. |
| GP16 | Economic agency | Can reason about tradeoffs, prices, work, firms, contracts, credit, insurance, investment, taxes, and long-run resource choices. |
| GP17 | Health agency | Can access valid health information, make risk-aware decisions, practice health-enhancing routines, and know when professional care is needed. |
| GP18 | Cultural literacy & taste | Can encounter art, literature, music, architecture, religion, and traditions with historical context and discriminate quality without mistaking preference for proof. |
| GP19 | Leadership & institution building | Can create goals, roles, decision rights, feedback, dissent, accountability, and learning processes for a team or institution. |
| GP20 | Stewardship & future judgment | Can reason about low-probability/high-impact risks, environmental constraints, intergenerational effects, reversibility, and option value. |
| GP21 | Craft & creation | Has at least one domain where knowledge has matured into practiced craft and can produce work others can inspect and use. |
| GP22 | Humility & update | Can find their own errors, change their mind publicly, seek expertise, and preserve unresolved uncertainty rather than manufacturing certainty. |

## Capstones

| ID | Capstone | Challenge | Evidence |
| --- | --- | --- | --- |
| CP01 | Personal mastery | Run a 12-week learning program in an unfamiliar field. | Delayed unseen test; teaching evidence; AI-use comparison |
| CP02 | Reality investigation | Measure and explain a real local physical/biological/social system. | Field notebook; model; uncertainty; external check |
| CP03 | Interpretive dossier | Read a major work and its historical/rival contexts; defend an original interpretation. | Long essay + seminar + revision |
| CP04 | Build / repair | Design, build, test, repair, or materially improve a physical or software system. | Requirements; prototype; failure injection; maintenance plan |
| CP05 | Institution audit | Diagnose an organization/institution across rules, incentives, power, information, metrics, and history. | Evidence map; stakeholder challenge; reversible redesign |
| CP06 | Health / life system | Design and execute an evidence-informed personal health or life-operations improvement without medical overreach. | Baseline; safe plan; behavior evidence; limits/referral criteria |
| CP07 | Financial agency | Create a long-horizon household financial policy and stress-test it against realistic shocks. | Cash flow; risk; contracts; scenarios; scam/fee audit |
| CP08 | Public communication | Explain one difficult technical/human problem to three audiences in three media. | Expert, public, youth versions + accuracy review |
| CP09 | AI stewardship | Delegate a consequential multi-step project to agents under explicit permissions and adversarial evals. | Contract; provenance; hidden tests; incident response; no-AI defense |
| CP10 | Civic / collective action | Improve a small real institution or community process with consent and accountability. | Before/after evidence; dissent; governance record |
| CP11 | Taste & creation | Curate a corpus, articulate criteria, then create/revise an original work or design within a tradition. | Blind ranking; curatorial statement; artifact; critique response |
| CP12 | Frontier problem | Integrate at least four trunks on an unresolved scientific/technological/civilizational problem. | Research dossier; prototype/model; ethics/governance; public defense |
