## Mastery

A concept counts when you can reconstruct it, solve an unseen case, state assumptions, test it, find a failure case, and defend your reasoning.

## AI use

Use AI throughout the curriculum. For concepts that support later work, make one serious independent attempt before asking for the answer. Check important results with calculation, experiment, simulation, or primary sources.
