# Start here

The Obelisk is intentionally not a 12-week course. It is a **lifetime formation architecture**. Use it in layers.

1. Read the foundational doctrine and graduate profile.
2. Diagnose your current knowledge-trunk and life-pillar coverage.
3. Choose a coherent sequence of prerequisites rather than random sampling.
4. For each module, cycle through reading, reconstruction, practice, making/investigation, critique, transfer, and defense.
5. Maintain both an **independent floor** and an **AI-augmented ceiling**.
6. Build one serious craft or specialization to external professional standards.
7. Return annually: update the curriculum inside yourself.

This repository distinguishes *coverage* from *mastery*. Reading every page is not completion.
