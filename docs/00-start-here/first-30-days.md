# First 30 days

The first month is deliberately narrow: **precise claims, proofs, limits, and models.**

| Week | Focus | Output |
|---:|---|---|
| 1 | Sets, logic, quantifiers | Formalize and negate technical requirements |
| 2 | Direct / contrapositive / contradiction | Three short proofs + error log |
| 3 | Counterexamples, induction, invariants | Safety invariant for a toy process |
| 4 | Limits and continuity | Model a sensor with saturation / dead zones |
