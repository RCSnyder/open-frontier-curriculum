## Premise

AI can reduce the time and labor needed to attempt some technical work. The reduction varies by task. Physical constraints, measurement error, domain knowledge, manufacturing, safety, economics, and institutions still limit results.

The curriculum emphasizes foundations that recur across many hard problems. It assumes regular use of AI and other tools, with independent checks for claims that matter.
