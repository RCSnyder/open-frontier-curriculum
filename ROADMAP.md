# Maintainer roadmap

Good first contribution areas:

- Verify textbook editions and official/open URLs.
- Add more primary-source problems and reproducible reference implementations.
- Improve prerequisite cross-links between module pages.
- Add domain-specific standards/regulatory source packs.
- Add alternative low-cost build paths for learners without labs.
- Add instructor/mentor oral-defense rubrics.
- Add translations without weakening technical terminology.
- Add historical/counter-reading pairs where one perspective dominates.
- Re-audit the Frontier 100 feasibility classes at regular intervals.
- Build a static dependency graph from Markdown front matter.
